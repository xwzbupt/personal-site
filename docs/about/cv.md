### 多源异构数据联邦查询平台

项目通过 Presto 为关系型、文档型、图数据和文件型等多类数据源提供统一 SQL 查询入口，并结合权限控制和文件缓存能力，解决数据孤岛、跨源查询以及重复远程读取问题。

**主要工作：**

- 参与多源异构查询平台的方案研究、搭建集成、部署和故障排查；
- 集成细粒度权限组件，参与策略匹配优化和权限信息保护；
- 基于 Connector SPI 开发 Neo4j Connector，完成元数据、类型和查询结果映射；
- 优化简单过滤、字段选择和数量限制下推，复杂图查询保留原生查询能力；
- 参与 Presto、Alluxio 与文件存储的缓存加速链路设计；
- 通过数据集准入、时间范围和动态路径路由控制缓存范围，降低冷数据污染风险；
- 参与现场部署、问题排查、交付文档和后续运行支持。

**项目结果：**

- 建立多类数据源统一查询与跨源关联能力；
- 完成图数据库接入和查询下推优化；
- 支持细粒度访问控制和审计链路；
